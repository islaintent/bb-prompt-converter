Program lo disimpen ke private Gist GitHub — jadi terbuka di mana aja (HP, laptop, browser beda) tanpa export manual.

Cara pasang (1x doang, ±30 detik):
1. Buka github.com/settings/tokens/new
2. Check centang Gist → Generate token
3. Paste token di bawah → Connect
Gist udah disiapin otomatis (private). Token cuma scope Gist, tersimpan di browser lo doang.
